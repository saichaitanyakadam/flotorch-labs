# Contact Center UI

React frontend for call analytics dashboard with AI-powered transcript analysis.

## Setup

```bash
npm install
npm run dev
```

## Features

- Real-time call analytics dashboard
- AI model selection (Bedrock/OpenAI/Groq/Anthropic/DeepSeek)
- Call transcript analysis
- Customer interaction metrics

## Tech Stack

- React 19 + Vite
- Tailwind CSS
- Axios for API calls
- React Icons
